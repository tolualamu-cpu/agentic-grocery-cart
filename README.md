# Agentic Shopping

Agentic Shopping is an early-stage product exploration for an agentic grocery cart builder and grocery optimization assistant.

The core product is not limited to recipe-based shopping. The durable product idea is a cart intelligence layer that can understand grocery intent, normalize it into purchasable needs, compare products across stores, optimize for user preferences, and produce an editable cart the user can trust.
